# PassGen

This is a terminal based password generator 100% made with Python.

## Getting Started

### Dependencies

Before running this project, make sure that the following is installed:

* [Python](https://www.python.org/downloads/) 3.x

You can check your installed version with:

```
python --version
```

### Executing program

1. Clone the repository:

```
git clone https://github.com/qwertz0-afk/PassGen.git
cd PassGen
```

2. Execute the app:

```
python main.py
```

If the terminal displays a trust warning, run:

```
.\main.py
```
